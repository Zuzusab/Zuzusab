###O mne
Som študentka odboru aplikovaná informatika a momentálne sa venujem viacerým oblastiam, ktoré ma v rámci informatiky zaujímajú. Učím sa základy strojového učenia (ML) a veľkých jazykových modelov (LLM), venujem sa dátovej analýze a popri tom skúšam aj tvorbu hier. Rada objavujem nové technológie a verím, že práve kombinácia vedomostí z rôznych oblastí mi pomáha lepšie chápať ich vzájomné súvislosti a hľadať možnosti, ako ich prepájať a využívať v praxi. Tento profil slúži ako moje  portfólio, v ktorom nájdete projekty, na ktorých som pracovala počas štúdia aj vo voľnom čase.
** Jazyky a technológie **
+ Python –  dátová analýza a vizualizácia, základy ML/LLM
+ Java – objektovo orientované programovanie
+ C# / Unity – tvorba hier a herná logika
+ SQL / MySQL – práca s databázami a dátami
+ HTML & CSS – tvorba a štýlovanie webových stránok
